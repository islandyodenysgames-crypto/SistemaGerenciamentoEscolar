# Sistema de Frequência Escolar

Sistema desenvolvido em PHP para gerenciamento de frequência escolar.

## Objetivo

Oferecer uma plataforma moderna para controle de presença de alunos, com foco em desempenho, organização e experiência do usuário.

## Tecnologias

- PHP 8.3
- MySQL
- HTML5
- CSS3
- JavaScript
