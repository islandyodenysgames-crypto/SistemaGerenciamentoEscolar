# Sprint 2.5.1 — Motor de Insights Automáticos

## Entrega

- Motor central de insights com prioridade, nível, categoria, período, explicação, ação sugerida e destino.
- Geração dinâmica de insights para alunos críticos, alunos em atenção, ocorrências críticas atrasadas, turmas em atenção e tendências de faltas/ocorrências.
- Painel "Insights prioritários" integrado ao topo da Central de Inteligência.
- Links para Central de Casos e Comparações Inteligentes.
- Layout responsivo e classificação visual: Crítico, Atenção, Positivo e Informativo.

## Banco de dados

Nenhuma migration é necessária nesta etapa. Os insights são calculados dinamicamente.
