# Sprint UI 2.0.3 — Cenário do Login e Tema Escuro Global

## Objetivo

Concluir a composição visual do login com escola e estudantes e corrigir a aplicação do modo escuro em todas as páginas do Sistema de Gerenciamento Escolar.

## Entregas

- Nova imagem limpa para o cenário do login, sem textos duplicados.
- Área fotográfica ampliada e reposicionada para mostrar escola, estudantes e ondas verdes.
- Preservação integral do formulário de login aprovado.
- Reforço das variáveis do tema escuro.
- Cobertura para cards, painéis, tabelas, formulários, modais, drawers, menus, cabeçalho e componentes antigos.
- Sincronização do tema no `html` e no `body`.
- Classes auxiliares `theme-dark` e `theme-light`.
- Atualização de versão dos arquivos CSS e JavaScript para evitar cache antigo do navegador.

## Critérios de aceite

1. O botão de tema alterna entre claro e escuro sem recarregar a página.
2. A escolha permanece após atualizar ou navegar.
3. O tema escuro altera o conteúdo principal, cabeçalho, menu, cards, tabelas e formulários.
4. Os ícones permanecem visíveis nos dois temas.
5. O login mostra claramente a escola e os estudantes como no modelo visual.
