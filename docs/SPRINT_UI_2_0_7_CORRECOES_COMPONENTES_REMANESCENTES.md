# Sprint UI 2.0.7 — Correções de componentes remanescentes no modo escuro

## Objetivo
Corrigir componentes ainda com fundos claros, cores originais inadequadas ou textos camuflados no tema escuro.

## Escopo concluído
- Inteligência Preditiva das Turmas: cards, cabeçalhos, indicadores, estados e ações.
- Alunos acompanhados: cards, métricas, filtros, anexos, paginação e blocos internos.
- Calendário de ocorrências: contraste dos dias com ocorrência em todos os níveis de intensidade.
- Calendário Escolar: cards de Programação cadastrada, eventos em destaque, períodos, badges e busca.

## Critérios de aceite
- Nenhum card listado permanece branco no tema escuro.
- Textos e ícones mantêm contraste legível.
- Cores semânticas continuam diferenciando estados e intensidades.
- Tema claro permanece inalterado.
