# Sprint UI 2.0.4 — Contraste do tema escuro e cenário do login

## Objetivo
Corrigir painéis claros remanescentes no tema escuro, reforçar a separação visual entre superfícies e restaurar a fotografia da escola com os estudantes no login.

## Entregas
- Correção do caminho relativo da imagem do login.
- Cenário fotográfico visível nos temas claro e escuro.
- Novos níveis de superfície, borda e sombra para o modo escuro.
- Cobertura de componentes antigos com fundos brancos fixos.
- Correção de textos camuflados por baixo contraste.
- Atualização de versão dos estilos para evitar cache antigo.
